### Note 2

- session `6cd5425f`

Expected generates a weak-symbol address check pattern: `lui v1, 0x37; addiu a0, v1, 0x12C0; beqz a0, skip; sw ra, 0(sp) [delay]; lw a0, 0x12C0(v1); jalr a0`. The function checks whether the ADDRESS of a function-pointer variable is non-zero (not the value), loads the pointer value, and calls it. This is the classic `if (&weak_sym != 0) weak_sym();` idiom used with weak symbols.

SNC 1.2.7503.0 does NOT support weak-symbol attributes needed to preserve this check. I tried: (1) `extern stop_fn_t _stop_hook_ptr` — SNC assumes extern non-null, folds `&sym != 0` to true; (2) `__attribute__((weak))` — silently ignored, check still folded; (3) `#pragma weak`, `#pragma weakref`, `#pragma weak_ref(...)` — all reported as Invalid pragma / syntax errors; (4) `__declspec(weak)` — syntax error; (5) inline asm `__asm__(...) : `+r`(p)` barrier with literal 0x3712C0 — compiler still folded the check; (6) explicit asm `lui %0, 0x37` producing an opaque base register, then C arithmetic for the offset and a second `*(base+0x12C0)` deref to force displacement form — this DID produce the null check but compiled to 13 instructions (52B) vs expected 12 instructions (48B): SNC put `sw ra, 0(sp)` before the branch instead of in the beqz delay slot, filling the delay slot with a nop. Best byte diff reached was 12/40 bytes without the check (simpler extern version).

Current `src/free_functions.c` has the clean C source (`if (&_stop_hook_ptr != 0) _stop_hook_ptr();`) which is semantically correct but compiles to 10 instructions without the null check. Root cause: SNC unconditionally constant-folds `&extern_sym != 0` at -O2 because it has no weak-symbol primitive. Without a way to mark the symbol weak or emit a `.weak` directive, this function appears genuinely unmatchable with this SNC version. A future agent could try: (a) finding an undocumented SNC pragma for weak symbols, (b) using a custom assembly-emitting preprocessor, or (c) the permuter — though mechanical permutation is unlikely to discover a source form that forces the check since it's a fundamental compiler limitation.
