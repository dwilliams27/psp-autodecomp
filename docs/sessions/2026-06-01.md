## Discipline — gaming HELD (byte-exact but rejected, not credited)

The north star is "what a respected matching-decomp project would do." These reached
0-diff only via codegen crutches with no genuine program semantics and were reverted:

- **eSimulatedController::GetPosition** (R9) — `__attribute__((naked))` 100%-asm body
  (hand `jr $ra`, hardcoded `$aN`, `.set noreorder`). Pure-assembly match.
- **gcPlayer::Reset** (R12) — `volatile int scratch; scratch = 0;` synthetic dead-store
  (meaningless local, emits a phantom `sw` to fake a byte).
- **eInputJoystick::GetIdleTime** (R15) — `volatile int best` local min-accumulator with
  no async semantics, load-bearing only as a stack-spill/non-CSE codegen lever.
- **eSimulatedState::Sleep** (R19) — `b->flags += 0;` no-op self-write, load-bearing only
  to emit a matching dead load/store.
- **eDynamicModel::Read / eShadowVolumeModelMtl::Read** (earlier this window) — `__asm__("ori %0,$0,1")`
  integer-MIPS constant-steering to materialize a C-expressible value.

Engine ban-list tightened to forbid these going forward (commit `2ad3f32`: naked bodies,
`ori`-constant seeds, synthetic volatile dead-store / no-op self-write crutches — even when
byte-exact). The legitimate near-miss outcome for an exact-size reg/sched residual is
`near_miss`, never a crutch.

### The dcast<T> cluster — the byte jackpot (58/306 matched this run, 122 KB total)

`dcast<T>(const cBase *)` RTTI downcasts: **306 untried / 122 KB / 0 matched** at session
start. All the same mechanical shape. **Recipe (record verbatim — bank the rest next time):**
- Symbol needs an **implicitly-instantiated PRIMARY template** `template<class T> T
  dcast(const cBase*)` (T is the *pointer* type) **+ an explicit instantiation**
  `template X* dcast<X*>(const cBase*);`. NOT an explicit specialization (mangles wrong).
- Body: a lazy nested-`if` `cType::InitializeType` registration cascade — **outermost
  (derived) static checked first, innermost (base) initialized first**; the base level uses
  the obj-family base slot + name-string ptrs (eAll: `D_000385DC`, strings
  `0x36CD74/0x36CD7C`; gcAll: `D_000385DC`, strings `0x36D894/0x36D89C`); a middle level
  (parent) carries no `New`; the **outer/derived** level carries `&Cls::New` as the **5th
  arg** and a **0-or-8 literal as the 8th arg** (varies per type) — feeding a `cBase`
  type-chain walk `for(t=obj->type@+4-dispatch; t; t=t->mParent@+0x1C) if(t==registered)
  return (T*)obj; return 0` written with **`||`-form null guards** (`registered==0||t==0`)
  to reproduce the `beqzl/bnel` branch-likely forms. Express `&Cls::New` as a raw
  `(cBase*(*)(cMemPool*,cBase*))0xADDR` cast.
- **Yield rules learned:** eAll/gcAll **280B (2-level) and 340B (3-level)** match ~100%.
  **400B+ (4-level)** cascades hit an **8-byte ADR-012 callee-save coloring** wall (s3↔s5
  tie-break across split `lui` hi-bases — not source-controllable). A minority of c*/gc*
  types hit the **8-byte ADR-006 branch-likely** wall (SNC declines the `beqzl`). Both →
  `near_miss`. **Per-type constants (outer slot, ordinals, &New, 8th-arg, cascade depth)
  VARY — each agent must read them from its own function's disasm**, never copy a sibling.
- Remaining: ~248 dcasts (eAll 400B+, plus gcAll/cAll ≤360B not yet attempted). Prefer
  ≤348B eAll, then gcAll ≤360B, next session.
