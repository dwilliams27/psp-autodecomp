## Reg-aware permuter scoring (committed 83e3304)

Built and validated an instruction-aware hill-climbing objective for `tools/permuter.py` so it
can attack REG_ALLOC near-misses (right instructions, wrong registers) — the byte-diff objective
gave no gradient there (one register swap cascades into thousands of differing bytes).

- `tools/mips_score.py` — MIPS decoder + `score_instructions() -> (guide_score, raw_score)`. Guide
  masks the branch-offset cascade + relocations, aligns streams (1:1, LCS realign only when 1:1
  shows structural diffs), weights `len ≫ struct ≫ register-locker`. raw stays the WIN CONDITION.
  Unknown/FP/VFPU opcodes are full-word compared (never silently register-masked).
- `tools/mutations_regalloc.py` — allocation-moving mutations (introduce/inline temp, live-range
  split, sink/hoist, rename), registered into the mutate() pool.
- `tools/test_mips_score.py` — decoder vectors + the safety test.
- `tools/permuter.py` — `--score-mode {bytes,insns}` (default bytes = unchanged), `--insn-gate N`.
  SAFETY INVARIANT: rank by guide, declare/save EXACT only on raw==0; acceptance is lexicographic
  `(guide, raw)` so a true raw==0 tying an already-0 guide is never discarded.

12-agent build + 7-way validation, then review-driven fixes (the lexicographic accept bug, LCS-only-
when-needed perf gate, conservative decoder, compound-assignment guard). 24 targeted tests pass;
bytes mode byte-identical to before. On gcDoEntitySpawn: guide 83519 vs raw 4142, and a short run
climbs where bytes mode found only `inf` — the gradient is real.

- **gcStreamedCinematic::gcStreamedCinematic (0x00161c00, 4108B):** raw 601/4108 (permuter improved

  cascading to every sp-offset. Needs 2 more stack locals; permuter can't fix frame size.

### Key learning
The reg-aware permuter is genuinely **last-mile**: it needs a structurally-complete input (guide
struct component == 0) to engage. With structural diffs present it correctly makes no progress (T1).
Future refinement: gate the permuter on the guide's *structural* component, not raw bytes, so it only
runs once a candidate is structurally exact. Per-target next steps are in the attempts README.
