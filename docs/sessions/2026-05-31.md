## MAJOR FINDING — VisitReferences mangling divergence (ADR-014)

While assembling the CPU-permuter near-miss pool, two things surfaced:

1. **The documented "#1 leverage" (permuter GPR-recoloring) is ALREADY BUILT.**
   `tools/mutations_regalloc.py` already registers `duplicate_local`,
   `introduce_temporary`, `inline_temporary`, `sink_computation`,
   `hoist_computation`, `rename_local`. No tooling work needed there.

2. **All 346 `VisitReferences` methods are blocked by a single mangling-algorithm
   divergence — and their CODEGEN IS ALREADY BYTE-EXACT.** See `docs/decisions/014`.
   Original SNC uses a cumulative (outer-inclusive) backref table inside
   function-pointer params (inner `unsigned int` → `TB`); pspsnc 1.2.7503.0 uses a
   fn-ptr-local table (→ literal `Ui`). Proven byte-identical on cObject (120B) and
   cBase (60B). No source change can fix it (exhaustively tested).

### OPEN OPERATOR DECISION (teed up — NOT actioned autonomously)

Two routes to credit these 346 byte-exact functions:
- **(A) Patch the SNC mangler binary** — norms-blessed (CLAUDE.md: fix compiler
  divergences in the compiler). ~2–4 day RE effort (cf. ADR-011 bnel patch), high
  blast radius (regression-test all 5214 matches before deploy). ROI is now far
  better than bnel ever was: 346 functions vs 2–7. Plausibly the biggest single
  unlock in the project.
- **(B) Normalize the verifier symbol gate** (`find_db_func_for_sym` in
  `tools/byte_match.py`) to treat the literal-vs-backref encodings of the *same*
  signature as equivalent. Hours, low technical risk (byte compare still gates), but
  in tension with the explicit "no post-processing of compiler divergences" norm.

**Decision deferred to operator.** Not implemented autonomously because it touches
the canonical match criterion / compiler binary and the explicit CLAUDE.md norm
points at (A). Reclassification of the 346 to `unmatchable_symbol_mangling` is also
held until A/B lands (if either is taken, they become creditable). Conductor will
NOT feed VisitReferences functions to the matching engine (guaranteed no-credit
under current tooling).
